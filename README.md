## 📋 Project Info

This **CTWGO (Connect To World, Go!)** project, a **Python-based** blog web application that enables users to interact with content and manage their accounts seamlessly.

📌 **Note**: This project was completed in **2019**, during my **3rd year at the University of Saskatchewan**.

- **Youtube demo link**: https://youtu.be/qDDPCy3vtOc
- **Github code link**: https://github.com/EvanHuang7/CTWGO

## 🛠️ Tech Stack

**Python, Flask, JavaScript, Jinja2, Bootstrap and SQLAlchemy**

## 🚀 Features

- **User Authentication**: Register, log in, and reset passwords via email verification.
- **Profile Management**: Update account details including username and profile picture.
- **Content Creation**: Create new blog posts with titles, body content, and optional images.
- **Post Interaction**: Like and comment on posts from other users.
- **Content Management**: Edit or delete your own posts and comments.
- **Search & Navigation**: Easily browse content with a search bar and pagination.
- **User Profiles & Rankings**: View user profiles and a leaderboard based on post likes.
- **Responsive Design**: Fully optimized for desktop and mobile devices.
- **About Page**: Includes background information about the app and its developers.
